# Google Flow free-tier visual assets — pilot

Mode: MANUAL_ASSET_IMPORT. No Gemini API calls, no browser automation, no paid tier.

## Guardrails
- Budget: maximum 50 Flow credits per day shared across both TikTok channels.
- Check the current per-generation credit cost in Flow before clicking Generate.
- Record actual credits spent; never assume Nano Banana image generation is zero-credit.
- Flow credits do not apply to the paid Gemini Nano Banana 2.1 API.
- Do not automate Google Flow web UI or store Google account cookies/credentials in GitHub.
- Existing Buffer publishing is unchanged; no post is created by this pilot.
- Do not treat AI-generated historical illustrations as documentary photographs.

## Asset handoff
1. Generate a 9:16 visual in Google Flow using an approved editorial prompt.
2. Download the resulting image to your computer.
3. Check visual accuracy, rights/terms and attribution requirements.
4. Upload the image through the existing media-ingestion process after validating its path and format.
5. Record asset origin, prompt, model, date, credit usage and editorial review in the media manifest.
6. Render MP4 only after all content and media validation gates pass.

## Pilot prompt — Tu Perro Feliz (29 October, 10:00)
Photorealistic editorial illustration, vertical 9:16. A calm medium-sized mixed-breed dog
on a loose leash sniffing grass in a quiet public park, attentive owner partially visible,
natural morning light, anatomically accurate dog, no dangerous plants, no food or trash,
no logos, no text, no watermark imitation. Designed as one still frame for a Spanish
educational video about safe scent-led walks. Avoid suggesting that an off-leash walk
is required.
